**Тема:** Классы и объекты  
**Выполнил:** Безруких Тимофей  
**Группа:** 550501

---

## Цель работы  
Создать библиотеку университета для пользования   
зарегистрированными изданиями благодаря ключевым   
принципам ООП, контроля ввода данных и контроля   
версий через Git.

---

## Структура проекта
* `Book.h` / `Book.cpp` — класс сущности «Книга» (валидация года издания, типа книги, статуса выдачи).
* `Reader.h` / `Reader.cpp` — класс сущности «Читатель» (валидация ФИО, телефона, автоматическая генерация ID).
* `Library.h` / `Library.cpp` — класс-менеджер для бизнес-логики и управления списками книг и читателей.
* `Menu.h` / `Menu.cpp` — функции отображения меню и обработки пользовательских команд (`show_menu`, `run_menu`).
* `Utils.h` / `Utils.cpp` — вспомогательные функции (безопасный ввод, очистка буфера, проверка на пустую строку, выбор элемента из списка).
* `main.cpp` — точка входа (создание объекта `Library` и запуск меню).

---

## Основной функционал

1. **Ручное добавление данных:** ввод новых книг и регистрация читателей через текстовое меню.
2. **Просмотр списков:** вывод текущего каталога книг и списка зарегистрированных читателей.
3. **Выдача книг:** выбор доступной книги из списка и выдача её читателю на 14 дней.
4. **Возврат книг:** освобождение книги и отметка о возврате.
5. **Контроль просрочек:** отображение книг, срок возврата которых истёк.
6. **Добавление новой книги:** ввод названия, автора, года издания и типа книги с полной валидацией.
7. **Удаление книги:** выбор книги из списка с подтверждением и проверкой статуса (нельзя удалить выданную книгу).
8. **Изменение ФИО читателя:** смена ФИО через сеттер с проверкой на пустоту и дубликаты.
9. **Изменение телефона читателя:** обновление контактных данных с проверкой длины номера.
10. **Защита от ошибок ввода:** устойчивость к вводу некорректных символов (букв, пробелов и спецсимволов).

## Ограничения предметной области

* Книга не может быть выдана, если она уже выдана.
* Книга не может быть возвращена, если она не была выдана.
* Нельзя удалить книгу, которая выдана читателю.
* Название и автор книги не могут быть пустыми.
* Год издания книги — от 0 до 2026.
* Тип книги — только «учебник», «методическое пособие» или «монография».
* Имя читателя не может быть пустым и не может состоять только из пробелов.
* Номер телефона — минимум 5 символов.
* Нельзя добавить книгу с уже существующим названием и автором.
* Нельзя зарегистрировать читателя с уже существующим именем.
* Нельзя изменить ФИО читателя на уже существующее у другого читателя.
